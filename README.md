# ERI Forge

Crée un site vitrine professionnel, moderne et industriel pour E R I — Entreprise Réalisation Industrielle, une entreprise spécialisée dans la chaudronnerie et la soudure, située au 600 route d’Orange, 84870 Loriol-du-Comtat, dans le Vaucluse.

Objectif

L'objectif est de créer une présence web professionnelle pour une entreprise industrielle locale qui n'a actuellement pas de site internet officiel identifiable.

Le site doit principalement servir à :

présenter clairement l'entreprise ;

mettre en valeur son savoir-faire en chaudronnerie et soudure ;

présenter ses réalisations ;

rassurer les clients professionnels ;

générer des demandes de devis et des prises de contact.
